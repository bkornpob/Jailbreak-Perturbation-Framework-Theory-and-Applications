# Jailbreak-Perturbation-Framework-Theory-and-Applications
Bhirombhakdi, K., Willis-Owen, D., &amp; N, K. (2026). Jailbreak Perturbation Framework: Theory and Applications. Zenodo. https://doi.org/10.5281/zenodo.20040972

We introduce the Jailbreak Perturbation Framework (JPF), a formal model of text-based jailbreak perturbations that includes both human-readable and non-human-readable search spaces and unifies a broad class of existing jailbreak tactics. Within this framework, we characterize perturbation operators, search procedures, and threat models in black-box text–text settings, and show how JPF instantiates both manual and human–AI co-search jailbreak generation. We then demonstrate JPF-based attacks against Lakera’s Gandalf benchmark using a lightweight assistant, InjectPrompt Companion 3.0 (\#C3), in conjunction with a sidebar assistant in the Comet browser (Perplexity AI), and show how well-known jailbreak templates—from universal adversarial suffixes to creative-writing role-plays and multi-turn dialogue attacks—arise as structured paths in the same perturbation space. Finally, we discuss implications for red-teaming methodology, model alignment, and the design of robust jailbreak defenses, and propose JPF as a common language for analyzing future jailbreaks.
